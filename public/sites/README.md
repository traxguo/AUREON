# Site photography

One 16:9 photo per reference site, named after the site `id` in
`data/sites.ts`:

    si.jpg  ro.jpg  bg.jpg  se.jpg  ua.jpg
    az.jpg  ge.jpg  tn.jpg  ly.jpg  dz.jpg

Recommended: 1600 × 900, JPEG, under 300 KB.

A missing file is not an error — the panel renders a typographic placeholder
with the machine's serial number instead of a broken image.
